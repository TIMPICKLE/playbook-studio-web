## 新版配色

- 深海军蓝：`#0C192C`
- 白色：`#FFFFFF`
- 绿色：`#3E9B58`（浅色版使用 `#2E8547`）
- 琥珀色：`#EAA127`（浅色版使用 `#D98B16`）

正式使用时，优先选择与页面背景匹配的透明背景版本；需要保证字形完全一致时，使用已转为路径的 Logo 版本。
