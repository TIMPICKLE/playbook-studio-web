## 发现、修复与复测

| 问题 | 根因 | 修复及验收 |
| --- | --- | --- |
| P1：导入期间开始分析，导入成功后仍留旧报告 | 初次清除结果发生在读文件之前，没有覆盖读文件期间启动的新请求 | 仅在资料持久化成功并采用后再次使分析失效；取消请求、丢弃晚回复；解析／保存失败保留基于原知识的有效报告 |
| P1：跑球和 Four Verticals 被无关传球原则填满 | 泛词“阅读、时序、责任”能单独使概念专用卡进入候选 | 内置概念卡增加受控概念词／别名检索条件；保留通用覆盖反例与球队原文检索。修复前独立场景 3 项失败，修复后 6 / 6 通过 |
| P1：分析页部分文字对比度不足 | 编辑器主题在 CSS 后部重新覆盖分析页的背景和文字颜色 | 移除旧分析页暗色覆盖，由分析模块拥有阅读界面；两种编辑器模式下正文对比度回归通过，真实浏览器复验浅色界面 |
| 集成：与最新手机适配分支冲突 | 两条分支均在分析样式末尾加入布局规则 | 合并保留知识区 grid-area；平板单列顺序完整；输入 16px、知识控件至少 44px，不丢失主分支触控改进 |
