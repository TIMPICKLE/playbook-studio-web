### 产品判断

建设可追溯的攻防对局学习工作台。每个判断应能回答：图上看到了什么；使用了什么防守假设；规则在什么条件下适用；还有什么未知；球员下一步观察什么。录像自动标注、战术搜索和静态对局分析分别评估。

## 架构边界

- 当前已具备实际 LangGraph 工具循环；扩展现有 harness，不重复搭建第二套。
- 几何证据与知识证据分开。图上相交不是同时到达；站位不是责任；前线阵型不是覆盖；静态图无法推算实证成功率。
- Cover 3 spot、Cover 3 match、Cover 2/Read 和 man 的条件不可混用。教练规则保留适用条件、反例、观察对象和来源。
- 采用可解释的词法/标签检索作为当前离线实现，不冒称向量语义检索。完整视觉嵌入、OCR、rerank 和影片跟踪列入可替换扩展边界。
- 本轮不变更战术本云端结构。知识包设备本地保存并明确标注；分析仅发送本次选出的有界证据，不静默发送全部资料。
- 不从标题确定真实战术，不从检索命中确定战术有效，不将资料来源有效等同于结论被证明。
- 分析完整性不能因加入通用规则卡而从 limited 自动升级；需检查已确认覆盖、图面充分性及引用。
- 每个异步导入/分析均处理取消与上下文失效，防止旧结果覆盖新战术本。

## 审阅状态

Team B 已完成产品/战术与架构/可靠性独立审阅，结论为「修订后实施」。采纳的 P0 修订：

1. `cover2` 表示具体规则未确认，增加明确的 `cover2_read` 选项；不能把普通 Cover 2 的概念结论套到 Read。
2. 无 API Key 仍提供真正的本地图面事实与来源检索，模型报告另行触发；不做伪进度或错误后的假成功。
3. 预设与导入来源命名空间隔离；来源版本按内容确定；重复导入去重，同 ID 不同内容拒绝。
4. 知识库导入、浏览器保存、单次检索 top K、关联扩展与模型上下文分别设上限；只发送当前明确召回的证据。
5. 模型工具只能搜索本次提交的授权片段；未知覆盖始终 limited；有条件情景引用至少一个真实图面对象，知识引用不代表推论已证实。
6. 异步导入捕获 workspace 与 generation；切换、删除、导入均使旧报告失效；本地保存失败可见。
7. 仅显式 parent/region/figure 关系可回补某一图；同页只能作为粗粒度页源，不能声称识别了该图。
8. 导入球队资料标为用户提供、未经外部核验；不能覆盖用户确认的防守规则。
