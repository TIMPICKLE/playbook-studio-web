# 数字战术板讲解试点手册

教练和球员能否在 30 秒内找到出手帧，指出 H、Y 中谁更深，并在球场上指给别人看？本试点另测视觉辨识，并用一个轻量对照判断收益是否主要来自事件按钮。所有人数、用时和门槛都是试验设计，实际参与者的观察需单独填写。

## 准备同一套编辑器

使用桌面浏览器与一份演示用本地工作区。下载两份 JSON，在编辑器左下角选择「导入战术本」，依次导入并确认追加。在战术列表中检查出现 **Play A** 和 **Play B**。两份文件使用中立标题和教学球员位置，演练均为 6 秒，各含 11 名进攻球员。受试前请一名教练单独确认题目真实、两份材料难度相近。[Play A](../samples/coach-film/pilot-a.json) · [Play B](../samples/coach-film/pilot-b.json)

| 条件 | 入口 | 从同一布阵页能看到什么 |
| --- | --- | --- |
| 常规 | [打开常规板](https://playbook-studio-tim.kind-wolf-6204.chatgpt.site/editor/local?filmPilot=baseline#editor) | 旧「战术演练」、播放、暂停、倍速、进度条 |
| 完整 | [打开讲解台试点](https://playbook-studio-tim.kind-wolf-6204.chatgpt.site/editor/local?filmPilot=film#editor) | 战术标题旁出现「讲解」。可点事件、选择球员、看同帧纵深 |
| 事件简版 | [打开常规板加事件按钮](https://playbook-studio-tim.kind-wolf-6204.chatgpt.site/editor/local?filmPilot=events#editor) | 进入旧「战术演练」后可点同一模型生成的关键帧，保留原有场地与工具 |

每个入口可以复用同一浏览器的本地工作区。主持人逐轮准备对应 URL 和战术，统一采用同一设备、浏览器、100% 页面缩放、颜色主题和常规布阵外观。恢复初始布阵与 0 秒、关闭向导、清空上一次选人，再交给参与者。参与者在任务中自行决定如何操作。完整板采用其真实的讲解布局。试点链接只影响这次页面访问，不修改持久显示偏好。

## 主持人脚本与轮换

第一轮 4 位教练与 4 位球员各做两道题。组内一位教练和一位球员，编号在各角色内随机分配。先询问是否愿意参与并记录匿名操作结果、有无看过这两套题。参与者仅看到当前编辑器；主持人拿着这份手册。

| 匿名编号 | 第一回合 | 第二回合 |
| --- | --- | --- |
| C1、P1 | A 常规 | B 完整 |
| C2、P2 | A 完整 | B 常规 |
| C3、P3 | B 常规 | A 完整 |
| C4、P4 | B 完整 | A 常规 |

对每个回合只读同一句任务，然后从布阵页起表。

> 请把这档战术停在四分卫出手的那一刻。H 和 Y 谁更深？指给我看你从哪里得出的判断。准备好时，请说“完成”。

一说完成就停表；30 秒到时结束该回合。主持人在此之前不提示入口、按钮、秒数或答案。判断依据需要指出同一帧上 H、Y 相对争球线及进攻方向的位置；直接在画面上指认可以计入。第一回合结束不揭晓答案。记录过往战术板经验、已看过本样例或意外技术中断的情况，技术中断单独报告。

### 本机计时与评分

安装项目所需的 Node.js 后，在仓库根目录运行以下命令。开始计时和停表各由主持人按一次回车。程序逐题记录停点、回答、依据和主持人是否提示。停表后另记该回合是否按过播放、是否看到停顿，以及当场实际采集的前台帧间隔 P95（毫秒）。缺少观察或采样时留空。记录按匿名编号保存在指定的本机目录，相同编号会提示已经记录。

汇总按条件列出使用播放与可见停顿的人次，各自的分母是对应问题有观察的回合。历史记录缺少这些字段时保留为空。现场 P95 与教学用时分别报告，以便复查「按播放后画面停住」或「直接点事件就完成」的具体回合。

```sh
node scripts/coach-film-study.mjs run C1 ../film-study-round1
node scripts/coach-film-study.mjs summary ../film-study-round1
```

参与者完成后，主持人可在浏览器开发者工具中读取原始停点，以相同精度判定两个条件的 ±0.1 秒误差。先停表再读取，读取不改变回放。

```js
document.querySelector('#coach-film-room [data-film-clock]')?.dataset.seconds
  ?? document.querySelector('#timeline')?.value
```

### 判定与反证

一次成功需要在 30 秒内无提示完成、停点距模型出手不超过 0.1 秒、球员判断及依据均正确。主持程序从这两份实际战术文件计算出手和纵深答案。每人只按自己的轮次计分。

建议初筛线为完整板至少 6/8 人成功，且两类角色分别至少 3/4 人成功。还需满足成功人数超过常规板，或两板成功人数相同且完整板用时中位缩短至少 25%。用时口径为同一人双臂均成功时计算个人缩短率，再取中位数；配对少于 4 人时保留该结论。逐次列明错误来自入口、停点、识人、纵深解释或操作中断。

完整板胜出后，另招一组未见材料的参与者，沿用四种分配，将表内“常规”换为“事件简版”。在新目录运行 `node scripts/coach-film-study.mjs run C1 ../film-study-round2 events`，汇总时使用 `node scripts/coach-film-study.mjs summary ../film-study-round2 events`。如果简版同样让人独立完成，且完整讲解和选人没有稳定额外收益，优先普及事件定位。8 人试点只用于产品投资取舍。

## 单独检验视觉辨识

主持人可先用项目实拍熟悉构图，观察相同视口、战术和时刻下两种画面的区别。正式盲测另外选择参与者未见的材料。[常规演练原图](assets/readme/coach-regular-frame.jpg) · [讲解台原图](assets/readme/coach-film-room.jpg)

在解题任务后做，改用参与者没见过的一套战术。主持人在两个模式各截同一战术、同一时刻、相同主题和等大视窗的暂停画面。讲解台保留正常的聚焦与关系线索。遮住模式名称、入口和选中标签，并各复制一张只保留同样范围球场的裁片。不要用一深一浅作为两种模式。

1. 随机决定左右顺序，先给完整界面一对。只问“如果要向队员解释出手一刻，你会选哪张？请指出你的依据”。
2. 看球场裁片时重新随机左右，记录是否还能指出近期跑位、站位参照或纵深关系。为减少对上一题的记忆，可换另一套未见战术重做这一步。
3. 记录每种画面的正确辨识数和依据。拟议门槛为完整界面至少 6/8 人答对且说出有效线索；仅靠深浅、记住位置或猜测的回答另列。

## 自愿教学扩展试验

以下实验与主持计时分开。可用一台电脑、已有编辑器的“复制战术”和教练准备的样例开展。若要记录学生学会了什么，另做隔日、无工具的新战术复测。

| 实验 | 一次训练怎么做 | 继续投入的依据 |
| --- | --- | --- |
| 三停一课与停帧提问 | 打开[本地课件试点](https://playbook-studio-tim.kind-wolf-6204.chatgpt.site/editor/local?filmPilot=lesson#editor)，给三处关键帧准备教练提示。先提问，再展示讲解。 | 同一教练在另一档战术或下一次会议再次制作、使用课件 |
| 错误跑法与版本对照 | 复制一套路线，只让 H 提前切入。随机播两个版本，请队员指出搭档间距首次明显变化的位置。 | 教练能复核队员说出的首个有效差异，愿意自己制作第二组 |
| 读防分岔 | 教练手工准备两张防守职责卡和两份经确认的处理。展示共同的开球前画面，让 QB 先说阅读依据，再播放分岔。 | 能说明“看见什么才改判断”，且分支依赖有数据或教练明确给定 |
| 位置组接力 | H 先讲起步，把处于相同方向和相同停帧的画面交给 QB，后者继续讲出手。 | 双方能准确接续同一帧，观察再次播放或重新找人的次数 |
| 概念跨阵型 | 教练把同一职责配在两种阵型中，先讲第一种，再让学员在陌生阵型上找对应球员与关键帧。 | 隔日仍能在新例中定位职责 |
| 阻挡接力与防守职责 | 在教练明确指定阻挡目标或区域责任的战术上选中心球员，逐段停帧，要求球员指认下一项任务。 | 每个目标与职责均能从编排中核实，观察能否减少顺序混淆 |

模型误标出手、进入讲解后破坏草稿、读数随主题改变或渲染回退后定位失真时，暂停这一条件的试用，保留复现步骤并修复后再验证。真实会议的二次自愿使用与操作失败原因单独记录，在解题、读图和技术回归分别通过后决定是否调整默认入口。
