# 球员管理、DEPTH CHART 与人员组验收

范围：本轮非 AI 严格验收。该报告覆盖球员名单、人员组、首发／替补顺位、分配和编辑器绑定；不覆盖 AI 或 GitHub Pages。日期为 2026-11-16。

## 验收结论与证据层级

人员与编辑命令专项 **75 项通过，0 失败、0 跳过**；中英文资源一致性另有 **10 项通过**。语法检查通过。证据为 [专项运行日志](evidence/roster-tests.txt) 与 [语言资源日志](evidence/roster-i18n.txt)。不把重复运行或该专项统计累加为全量测试结果。

这些结果来自 Node、领域函数和 Happy DOM 中的真实应用宿主事件；拖拽使用 DOM `dragstart / dragover / drop / dragend` 事件和 `DataTransfer`，不能替代浏览器真实指针、iOS 触摸、原生弹窗排版或软键盘检查。该报告的“通过”均限定在下表证据层级；浏览器与真机结论应由总体验收另行补充。

## 审查发现与修复

| 编号 | 优先级 | 问题 | 修复与复验 |
| --- | --- | --- | --- |
| R01 | P1 | 原实现只有按钮调序与位置表单，专项要求的球员拖拽尚未实现 | 增加桌面阵型首发／替补顺位拖拽和名单分配。拖到其他位置时，来源首发留空，目标旧首发顺延；所有受影响顺位一次提交、一次撤回。保留按钮调序；触屏／键盘增加“查找球员 → 分配 → 选择位置”的明确等价路径 |
| R02 | P1 | 将 QB 首发拖至 X 后，QB 明确空缺；再次从 DEPTH CHART 应用首发时，旧 QB 绑定会阻止 X 获得这名球员 | 新完整人员应用计划把同名唯一、明确空缺且已有绑定的位置纳入解除绑定，与新首发一起原子应用。预览分别展示首发与清空数量；保留棋子位置、路线和所有图面几何。未映射、重复位置标签、对方球员和无效名单 ID 不清空 |
| R03 | P1 回归项 | 拖拽可能发生过期数据、重复 drop、取消或权限变化，不能按旧画面写入 | 拖拽记录战术本、人员组和全部顺位快照，提交前核对；Escape／dragend 失活旧拖拽。只读、换组、换本、重复首发、满顺位、删除球员均有拒绝路径 |
| R04 | P1 回归项 | 失败保存、取消确认和编辑器撤销必须保留最新人员信息 | 补齐球员新建、位置编辑和人员组复制保存失败后保留草稿并重试；验证删除取消、并发修改拒绝、改名／删除后图面 undo 不恢复旧人员绑定 |

R01 与 R02 是实际实现缺口及可复现的一致性问题，已补实现并以行为回归验证；其余表格记录实际执行的恢复与异常用例，不据此推断真实设备已通过。

## 主要操作路径与实际结果

| 操作路径 | 实际步骤／断言 | 结果与证据层级 |
| --- | --- | --- |
| 名单查找与编辑 | 按姓名、号码、位置搜索；中英文大小写与特殊字符不影响查找；编辑只更新修改字段，保留其他成员更新 | 通过：DOM 宿主和领域数据 |
| 保存失败后恢复 | 新建球员、修改位置顺位、复制人员组；提交器返回失败；确认表单与所选数据保留；恢复后再提交 | 通过：每个新建操作只生成一条记录，失败阶段不写数据 |
| 删除与取消 | 打开球员／位置删除确认，按取消或 Escape 返回原编辑草稿；确认前不改变数据；确认时复核其他成员更新 | 通过：原生 dialog DOM 事件；未验证系统实际焦点圈与弹窗尺寸 |
| 首发、替补与视图 | 切换进攻、防守、特勤及人员组；切换阵型图、表格、首发列表；提升首发和上移／下移替补 | 通过：无须弹窗即可调序，原“提升”对调语义保留 |
| 模块往返 | 选择人员组、视图、查找球员、位置与筛选；离开后返回；再切换另一战术本 | 通过：恢复原本状态，另一战术本独立；失效 ID 安全回退 |
| 桌面跨位置拖拽 | 已有 QB 首发拖到 X；来源保留空首发及替补；X 旧首发成为替补；点击撤回 | 通过：DOM 拖拽模拟；一次保存与一次撤回覆盖两个位置 |
| 顺位表拖拽 | 将第 2 替补拖到第 1 替补；把查找出的名单球员拖到空位置的替补区 | 通过：顺位正确，空首发仍为空，不自动把替补设为首发 |
| 查找后的拖拽 | 查找一名替补，阵型图显示该替补；拖动该标记 | 通过：操作可见替补，不误移动该位置隐藏的首发 |
| 触屏／键盘等价分配 | 查找球员，点击分配，再点选阵型位置；表格可选择“放入首发／追加替补”；取消或 Escape | 通过：按钮和键盘取消 DOM 路径；未把它标为 iPhone／iPad 手指操作通过 |
| 拖拽取消与过期 | 开始拖拽后取消、晚到 drop、外部顺位更新、换本或撤权 | 通过：均不写旧数据；失败保存可重新拖拽重试 |
| 拖拽冲突 | 拖入已包含该球员的位置、重复首发、超过 10 个顺位、来源已删除 | 通过：拒绝且不改变原名单 |
| 编辑器人员同步 | 先在图面应用 Spread；DEPTH 把 QB 拖至 X；回编辑器预览“清空 1 个绑定”；应用后 undo／redo | 通过：完整 app 宿主，路线及几何不变；图面撤销不回退已保存的新 DEPTH 数据 |
| 全空人员组 | 在 DEPTH 表单将所有首发清空；回编辑器选择该组，预览并应用清空绑定，再撤销 | 通过：全空组仍可选择；仅明确对应的位置解除绑定，一次撤销恢复图面 |
| 格式持久化 | 将真实宿主保存到 localStorage 的新人员和图面数据 decode、encode、再 decode | 通过：完整格式往返；不等同于真实浏览器重启或跨设备同步 |
| 五人腰旗与只读 | 推荐五人组但不覆盖既有十一人组；只读仍可查找和查看，不能创建、拖拽或更改顺位 | 通过：领域和 DOM 用例 |
