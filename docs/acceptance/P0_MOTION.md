# 战术板与 DEPTH CHART 动效验收

本轮基线为 `d948017`。三个操作分别关系到编辑时能否跟手、撤销后能否理解变化、换人后能否认清去向。每项都有可独立复测的操作。

| 任务 | 实施范围 | 放行标准 |
| --- | --- | --- |
| T0 建立基线 | 固定战术数据、视口、动作和计数方式 | 新旧版本运行同一组手势。记录球员、路线和采样量，区分 SVG 写入次数、主线程耗时与帧间隔 |
| T1 拖动跟手 | 将单次手势涉及的 SVG 节点及依赖绑定到本次预览 | 拖动球员、路线节点、组、区域和标注时，目标及依赖和完整绘制结果一致。无关节点零几何写入。松手只记一笔，取消后草稿和历史均无残留 |
| T2 撤销与重做 | 用已提交的前后状态呈现同一战术的局部变化 | 改路线后撤销／重做时能辨认变化路线。无关对象静止；连续操作、立即拖动或离开编辑器后，数据和命中位置与最终状态一致。减少动态时即时显示结果并提供文字反馈 |
| T3 DEPTH CHART 调人 | 从一次换人事务识别球员的来源、去向与顺位 | 把 QB 移到 X，检查新旧位置、被顶替球员及后备顺位。拖拽和键盘／点选结果一致。撤回后还原，滚动与可操作焦点保持，减少动态时仍可读出结果 |
| T4 集成与发布 | 独立复测、回归、构建及核对发布源 | 记录自动化通过数和实际浏览器结果，列出设备限制。发布内容与验收源代码一致 |

## 操作复测

| 入口 | 操作 | 验收结果 |
| --- | --- | --- |
| 战术编辑器 | 拖动接球手、成组球员、持球人、封堵目标、路线节点、区域或标注 | 局部绘制与完整绘制的 125 次几何对照一致。拖动 Motion 终点时关联路线同步跟随；若后继节点越界，整笔回滚。新建区域首次插入时更新场地结构，后续拖动只写该区域 |
| 战术编辑器 | 移动 X → 撤销 → 把 X 拖开再放回原位 → 重做 | 原位松手保留历史和重做入口；重做准确恢复首次移动 |
| 战术编辑器 | 移动 Mesh 的 X → 撤销 → 重做 → 撤销 | 在 Chromium 中，球员起点为 (278.07, 448.35)，终点为 (319.95, 411.50)（SVG 坐标）。每次操作都回到对应位置；状态区读出事务名 |
| 战术编辑器 | 对 Go／Post 路线连续撤销与重做，在动画中按下球场 | 数据与命中路径即时恢复，局部覆盖层呈现路线形变；下一次操作可接管。减少动态时保留文字反馈，跳过形变 |
| DEPTH CHART 顺位表 | 键盘选择 QB 首发 TIM，在 X 上选择“放入首发”，再撤回 | Chromium 中，QB 显示待定，Casey 保持第一替补；X 由 TIM 首发，Alex 顺延。撤回后 TIM 和键盘焦点回到 QB，Alex 恢复 X 首发。来源与目标标记同时反向 |
| 数字球场 | 拖动无路线、无封堵依赖的棋子；再拖动有路线的棋子 | 渲染器回归确认，独立棋子移动可唤醒绘帧而无需重新生成场地纹理；当底图内容有变化时仍刷新 |

拖动几何与中断的永久回归见 [局部绘制](../../tests/field-gesture-geometry.test.mjs)、[编辑器手势](../../tests/editor-gesture-acceptance.test.mjs) 和 [撤销动效](../../tests/history-transition.test.mjs)。换人的三种视图和输入路径见 [DEPTH CHART 回归](../../tests/depth-drag-workflow.test.mjs)。

## 拖动开销

传统球场固定 11 对 11、10 条路线、1 个区域和 1 条标注。通过编辑器原有指针入口，每个手势移动 96 次。在相同 DOM 环境中，两版的松手坐标均与实时预览一致，一次撤销可还原初始战术。

| 手势 | 基线 SVG 属性写入 | 本轮写入 | 基线无关写入 | 本轮无关写入 |
| --- | ---: | ---: | ---: | ---: |
| 单人 X | 5,088 | 288 | 4,800 | 0 |
| 双人 X + Z | 5,088 | 576 | 4,512 | 0 |

复测命令如下，从仓库根目录执行。两版使用同一份基线生成的战术并在内存中运行，拖动及撤销不会覆盖本地已有战术本。详见 [逐组数据](evidence/p0-drag-dom.json)。

```sh
node scripts/acceptance-drag/prepare.mjs
node scripts/acceptance-drag/dom.mjs base
node scripts/acceptance-drag/dom.mjs candidate
```

## 放行检查

基线的 853 项 JavaScript 回归全部通过。本轮全量为 867 项通过、0 失败、0 跳过，另有 4 项 Python 测试通过。`npm run check`、`npm run typecheck` 和生产构建通过。核对了生产输出中 17 份变更的编辑器资源，它们与验收源码逐字节相同。开发用的对照战术快照及浏览器探针未进入发布包。

本轮使用桌面 Chromium。iPhone／iPad Safari 实机触摸及真实 GPU／WebGL 像素效果尚未验证。在持续的设备帧率测试完成前，SVG 写入减少量仅用于衡量编辑器的局部更新开销。
