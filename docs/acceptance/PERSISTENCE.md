# 保存、恢复、导入导出与云同步验收

本轮按用户调整后的范围，排除 AI 功能与 GitHub Pages。验收基线为 PR #50 发布源码。通过状态只覆盖下表标明的实际执行层级；没有将协议 fixture、Happy DOM 或 SQLite 内存数据库当作真实账号、系统文件下载或实体打印验收。

## 本轮新增缺陷与修复

| 编号 | 优先级 | 复现与影响 | 修复与证据 |
| --- | --- | --- | --- |
| SAVE-F01 | P1 | 同一本战术本的旧 PUT 尚在途，重新载入较新版本后，旧成功回执将当前 revision 从 4 回退为 2，并用旧快照替换较新基线；旧 409 回执也会将 revision 从 5 回退为 2 | `CloudSync` 增加独立的载入代次；保存开始时捕获，成功／失败返回后核对。较新的本机待同步内容和远端基线保留。新增两项回归修复前均失败、修复后通过 |
| SAVE-F02 | P1 | 旧轮询在新版重载后才返回：完整回包会将 revision 从 7 回退为 2，`unchanged` 回包也会将新版编辑权限改回旧 viewer | 同一载入代次用于轮询成功和异常回包；迟到请求不再接管新版数据、权限或错误状态。完整回包和权限回包修复前失败；完整、权限及迟到 403 三条子用例最终通过 |
| SAVE-F03 | P1 | JSON 文件读取尚未完成时离开编辑器，读取结束仍在球员管理模块弹出导入确认；慢文件 A 也可能在已选择文件 B 后迟到，替换最新确认 | 主集成增加战术本目标、编辑器会话与最新文件读取序号守卫；读取完成与确认提交分别检查，只有最新读取清理输入。离开模块、离开后回返、慢 A → 新 B → A 迟到三条实际宿主回归最终通过 |

载入代次与已有编辑 `generation` 分开：连续编辑仍允许正在执行的保存确认已发送版本，并保留后来输入的待同步内容；只有真正替换已载入战术本的事件使旧请求失效。

## 已执行用例

| 编号 | 操作／故障 | 预期与实际执行范围 |
| --- | --- | --- |
| SAVE-01 | 本机文件无法解析／坐标越界 → 下载原文件 → 重试 → 文件恢复可读 | 原始字节保持，不使用示例覆盖；原文件 Blob 内容逐字节一致；重试成功才解除只读。实际宿主 DOM 与序列化通过 |
| SAVE-02 | 浏览器临时拒绝读取存储 → 重试；确认替换时写入失败 → 再次重试 | 失败保留原始存档和禁用编辑状态，替换需要明确确认及成功写入。实际异常注入通过 |
| SAVE-03 | 在球员模块恢复可读文件 | 当前球员列表原位更新，不强制跳到编辑器，已有文件保持。实际宿主 DOM 通过 |
| SAVE-04 | 本机完整备份序列化 → 解码；无效格式／几何／引用／重复 ID 导入 | 合法示例完整往返；非法文件在写入前拒绝。实际模型校验通过 |
| SAVE-05 | 云端保存成功、保存中继续编辑、无效成功 JSON／非法 revision 回执 | 确认必须是期望的下一版本；在途后的新编辑仍待保存；无效确认不得清草稿或显示成功。实际同步类和协议 fixture 通过 |
| SAVE-06 | 离线 → 本机草稿 → 新实例载入 → 合并独立远端变化 → 重试 | 草稿跨实例恢复；独立变更合并；未同步数据在失败后仍可恢复。真实序列化存储与协议 fixture 通过 |
| SAVE-07 | 配额不足／本机存储不可用且离线 | 明确显示仅内存存在，不冒称草稿已保存；存储恢复后重试，成功同步再清草稿。实际异常注入通过 |
| SAVE-08 | 同处编辑冲突／删除与编辑冲突／几何合并不合法 | 不自动覆盖任一方；保留可解码本机版本并要求处理；显式使用远端后清理。实际三方合并与同步类通过 |
| SAVE-09 | 界面渲染异常、权限撤销和只读操作 | 不将渲染错误当离线或成功；保存失败不丢草稿；viewer 经按钮、键盘或合成事件也不能写入。实际宿主 DOM、同步类与 SQL API fixture 通过 |
| SAVE-10 | 旧客户端保存 DEPTH CHART、并发 compare-and-swap、历史恢复 | 保留新版人员数据；旧 revision 拒绝，数据库不产生假快照；恢复形成新 revision。实际 SQLite 内存数据库与 API 路由通过 |
| SAVE-11 | 3D PNG 完整捕获／兼容模式平面导出／无法捕获时回退 | 不二次投影，不丢失球员；图像来源和兼容描述正确。实际导出模块回调与结构断言通过，未代表 WebGL 硬件或真实文件下载 |
| SAVE-12 | 同本重载后旧保存／冲突／轮询／权限异常迟到 | 新 revision、远端基线、本机待保存备注与新版权限不被旧请求覆盖。新增可控延迟回归通过 |
| SAVE-13 | 本机 JSON 导入追加 → 撤销；引用同一球员的人员组与战术一起追加；5 人制备份追加 | 现有战术不被丢弃，所有 roster ID 及人员引用一致重映射；一次撤销恢复完整旧数据；非法备份不出现确认。实际模型和编辑器宿主通过 |
| SAVE-14 | 当前／全部打印范围 → 两张战术本、九格腕带、CALL SHEET 预览 | 数量、页数与列表内容符合当前数据；打印 SVG marker 使用独立作用域。实际宿主打印 DOM 通过，系统打印窗口和输出介质另验 |
| SAVE-15 | 慢 JSON 读取 → 离开编辑器／离开后回返／随后选择新文件 | 旧读取不再弹确认或抢占最新文件；最新确认导入两张战术，旧文件的一张不会被误导入。三条延迟读取宿主回归通过 |

## 不能由本页证明的项目

- 真实云端账号登录、断网重连和跨用户并发尚未通过真实生产账号执行；本页实际使用协议 fixture、数据库测试与 DOM 宿主。
- 浏览器实际文件下载、文件选择与系统打印窗口由主浏览器验收另记；本页 Blob、SVG、PNG 和打印 DOM 证据不能替代它们。
- 本机配额、只读文件和网络异常采用明确的测试注入，不代表已覆盖每一种浏览器或 iOS 存储策略。
- AI 与 GitHub Pages 不在本轮验收范围，也不计入通过或阻塞数量。
