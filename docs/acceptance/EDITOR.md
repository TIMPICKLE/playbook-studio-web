日期：2026-11-16。范围：球员、路线、区域和文字编辑，撤销／重做，本机保存和恢复，传统与数字显示的共享几何。本轮不验收 AI 行为和 GitHub Pages。

## 证据层级

- **领域自动化**：Node 原生测试，执行实际几何、命令、序列化、历史与数字投影代码。
- **宿主 DOM 集成**：Happy DOM 加载实际 `web/index.html` 和 `web/app.js`，发送 DOM 鼠标／触摸指针／键盘事件并检查真实存储结果。SVG 屏幕矩阵／边界在测试中确定；这不证明真实浏览器的 CSS 命中、系统触摸、WebGL、原生离页提示或 Safari 行为。
- **真实浏览器、物理设备**：本专项未独立操作浏览器或真机。主验收记录需补相应证据，不能把下表自动化的“通过”当作真机通过。

测试环境偏差：Happy DOM 20.8.4 直接解析原始 `<select><option value="a">LT</option><option value="b">LG</option><option value="c" selected>QB</option><option value="d">X</option></select>` 时，错误地将 `b` 作为 value。新增离页用例仅在前置条件中规范化已提交 SELECT 默认值，避免用模拟器的 parser 缺陷冒充产品错误。生产逻辑仍读取当前控件值，未改为信任 `selected` 属性；实际浏览器球权默认选项需主矩阵独立核实。

本模块不以执行速度代替帧率，不以 DOM 的一次通过代替不同尺寸浏览器和 iOS 验收；真实操作证据由主验收矩阵合并记录。
