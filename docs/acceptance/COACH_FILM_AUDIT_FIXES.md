# 数字战术板联合审核修复验收

本轮从公开版 v62 的复现步骤出发。教学示例使用内置美式橄榄球战术 Mesh，测试中的工作区、球队成员和问题均为样例数据。

| 任务 | 复现与验收标准 |
| --- | --- |
| 课件续编 | 保存 Q1、Q2，离开讲解再进入，直接补 Q3。重开能看到三题，另一个工作区的同名战术看不到这份课件。 |
| 协作时保留备课现场 | 保留已收录和正在输入的题、选人、参考帧及焦点。队友改名或背号后继续备课。队友改路线或时序时列出待复核停点，教师可调整并逐一确认。 |
| 投屏先问后答 | 在 2.0 秒选中 H、Y，记录「谁更深、差多少」。揭晓前学员可观察站位，场上、侧栏、读屏和同屏助手均不直接给出答案。揭晓后恢复该题答案和读数。 |
| AI 版本与保存结果 | 预览出手时间 1.4 秒时，读板与读讲解都指向预览。尝试跳转会要求先处理预览。并发保存时由实际设备的存储结果决定回执，先保存的课件和后写者草稿受到保护。 |
| 三个入口同一时钟 | 在相同的低频前台回调下，常规、仅事件、完整讲解都在墙钟 2 秒到达 Mesh 出手。起播后首帧延迟 1 秒应显示 1 秒。墙钟 1.25 秒切至 2 倍后，在 2 秒和 3 秒分别显示 2.75、4.75 秒。 |
| 球权、键盘与读数 | Cover 3 和 Nickel Blitz 不自动标记端锋持球。显式指定防守球权可归档并在讲解中读出。Esc 从替换或编辑表单逐层返回。在球员上按 Alt+方向键可切停点，文本输入保留编辑快捷键。两种主题使用同一套纵深读数。 |
| 卡顿与拖动 | 每轮同时记录帧间隔、长停顿占用的墙钟时长、连续输入到场地提交及下一次对应画面采样。松手须落在最终值。原始数值应可独立复算公布的百分比。 |

实际回放使用同一份 22 人、10 条路线的 Mesh 样本。教学时钟的正确性由可控时间测试验证，帧间隔与输入响应由浏览器另行采样。[基准与复测方法](../../scripts/bench-digital/coach/README.md) · [教学试点手册](../COACH_FILM_PILOT.md)
