# Web 静态品牌资源

`brand/` 中是 Playbook Studio 的产品品牌资源，源文件同步自 `docs/assets/brand/`。

- `playbook-studio-logo-dark-transparent.svg` / `playbook-studio-logo-light.svg`：深浅主题完整 Logo（透明背景）。
- `playbook-studio-logo-dark.svg` / `playbook-studio-logo-editable.svg`：深色展示版与可编辑源文件。
- `playbook-studio-icon.svg` / `playbook-studio-icon-black.svg`：独立 `P` 路线战术图标，用于侧栏、favicon、登录与落地页。
- `icon-32.png`、`icon-180.png`、`icon-192.png`、`icon-512.png`、`icon-maskable-512.png`：由新版图标 SVG 渲染，用于 favicon、Apple 触控图标和 PWA。
